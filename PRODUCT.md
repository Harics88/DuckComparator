# Product

## Register

product

## Users

Data engineers, database administrators, QA engineers, and reconciliation operators who run or review scheduled Oracle table comparisons through Airflow. They need to understand the state of a comparison quickly, then move from summary counts to row- and column-level evidence without reconstructing the result manually.

## Product Purpose

Compare large Oracle tables across independent database connections using primary keys, surface exact matches and differences, and produce trustworthy HTML and Excel evidence. Success means an operator can immediately see whether two tables agree, understand the scale and location of any mismatch, and investigate the affected keys and values.

## Brand Personality

Clean, appealing, and state-forward. The report should feel calm and operationally trustworthy while making the comparison outcome unmistakable.

## Anti-references

- Not a legacy administration screen with tiny text, dense gray grids, and crowded controls.
- Not an over-minimal report that hides primary keys, counts, or investigative evidence.
- Not an alarm wallboard dominated by bright warnings, excessive red, or visually noisy charts.

## Design Principles

1. Lead with the comparison state and its operational meaning.
2. Preserve a clear path from summary to evidence.
3. Use density where it supports investigation, never as visual clutter.
4. Reserve emphasis for meaningful state and exceptions.
5. Make every reported count traceable to detailed output.

## Accessibility & Inclusion

There is no formal compliance target. Maintain readable contrast, descriptive labels, and status communication that does not depend on color alone.
